# SoundGraph — Evidencia del arranque y la semilla

**Fecha:** 21 de noviembre de 2026 · **Alcance:** persistencia local y consulta de recomendaciones; no incluye API ni interfaz.

## Entorno y ejecución

- Host macOS arm64; Docker Desktop Engine 29.1.3 y Compose 2.40.3-desktop.1.
- Motor relacional PostgreSQL **17.12**, documental MongoDB **8.0.38** y grafo Neo4j **5.26.33 Community**.
- Proyectos Compose y volúmenes separados. `soundgraph-dev` arrancó con volúmenes nuevos y quedó activo con los tres motores saludables. `soundgraph-test` se detuvo después de las pruebas, conservando sus volúmenes. Ningún motor publica puertos en el host.

## Resultados observados

| Comprobación | Resultado |
| --- | --- |
| Carga reproducible | La carga autenticada se completó en ambos proyectos; la auditoría no encontró referencias huérfanas. |
| Repetición | La semilla conservó 4 perfiles, 1 playlist, 3 fichas y 5 relaciones de escucha, sin sobrescribir una ficha ni una playlist editadas para la prueba. |
| Validación documental | MongoDB rechazó una ficha sin sección editorial con código 121. |
| Integridad relacional | PostgreSQL rechazó una playlist cuyo propietario no existe mediante clave foránea. |
| Auditoría entre motores | Detectó un nodo de canción sin identificador y un perfil de grafo ausente en SQL; se retiraron los datos de prueba y la auditoría volvió a pasar. |
| Consulta de grafo | Para Ana, devolvió `c-cream` con afinidad 1 aunque el mismo perfil comparte 2 escuchas. La ficha correspondiente en MongoDB tiene título «C.R.E.A.M.». Para un perfil nuevo devolvió cero candidatos. |

**Resultado de pytest:** 6 pruebas de integración pasaron en 1.28 s. Ese tiempo es la duración de la suite, **no** una medición de latencia del producto. Se compararon los SHA-256 de los dos artefactos históricos; permanecieron intactos.

Para repetir las pruebas, seguir [el README](../../README.md). Esta evidencia respalda la preparación de las tres bases y el cruce por identificador. No verifica todavía el flujo de recomendación y guardado desde una aplicación.
